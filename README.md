# Facial_Expression_Analysis
This project presents a lightweight deep learning pipeline for Facial Expression Recognition (FER) developed using Keras with a TensorFlow backend, alongside an adversarial attack framework that demonstrates how emotion classification systems can be systematically deceived. The model is trained on the FER2013 benchmark dataset, which consists of 35,887 grayscale face crops at $48 \times 48$ pixel resolution categorized across seven distinct emotional states: angry, disgust, fear, happy, sad, surprise, and neutral. 

The primary neural network architecture is streamlined for constrained computational environments, featuring six convolutional layers with ReLU activations, three max-pooling layers placed after every two convolutions, and two dropout layers to curb overfitting before feeding into a dense SoftMax classification head. In addition to standard image classification, the project investigates computer vision feature extraction techniques—such as extracting key facial landmarks across the eyebrows, eyes, nose, mouth, and jawline using dlib pre-trained on the iBUG 300-W dataset—to address challenges related to occlusion, varying head poses, and illumination.

A core component of this repository explores adversarial robustness through an input-space gradient ascent algorithm designed to "cheat" the classifier. By defining a custom loss function that minimizes the negative predicted probability of a selected target emotion, the method iteratively computes input-pixel gradients to maximize the model's confidence in that target class—such as transforming an input neutral face into a high-confidence happy prediction. The optimization stabilizes image updates via gradient standard deviation normalization and grayscale clipping to maintain valid pixel bounds. This exploitation highlights significant security vulnerabilities in biometric emotion tracking, including potential risks like emotion spoofing in automated surveillance, unauthorized manipulation of affective access controls, and the undermining of AI-driven psychological or behavioral monitoring systems.
